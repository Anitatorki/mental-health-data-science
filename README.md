# Mental Health & Wellbeing Data Science

A practical data science project focused on mental health and wellbeing data.

## Goal

Build a portfolio-quality healthcare and psychology data science workflow from data preparation through analysis, visualization, and machine learning.

## Learning Path

1. Python and data preparation
2. Data cleaning and validation
3. Exploratory data analysis (EDA)
4. Descriptive and inferential statistics
5. Data visualization
6. Feature engineering
7. Machine learning
8. Model evaluation
9. Healthcare and psychology-focused interpretation
10. Reproducible reporting

## Project Principles

- Use public, synthetic, or appropriately de-identified datasets only.
- Do not include private patient information.
- Separate statistical findings from clinical interpretation.
- Document assumptions, limitations, and reproducibility steps.
