# Mental Health & Wellbeing Data Science

A practical data science project focused on mental health and wellbeing data.

## Goal

Build a portfolio-quality healthcare and psychology data science workflow from data preparation through analysis, visualization, and machine learning.

## Learning Path

1. Python and data preparation
2. Data cleaning and validation
3. Exploratory data analysis (EDA)
4. Descriptive and inferential statistics
5. Data visualization
6. Feature engineering
7. Machine learning
8. Model evaluation
9. Healthcare and psychology-focused interpretation
10. Reproducible reporting

## Project Principles

- Use public, synthetic, or appropriately de-identified datasets only.
- Do not include private patient information.
- Separate statistical findings from clinical interpretation.
- Document assumptions, limitations, and reproducibility steps.

## Tools

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Scikit-learn
- Jupyter
- Git/GitHub

## Status

**Day 10 — Multiple Linear Regression**

Completed data loading, cleaning, exploratory analysis, descriptive statistics, visualization, correlation, simple linear regression, model evaluation, and multiple linear regression.

Day 10 uses sleep hours, exercise days per week, and work/study hours as predictors of a synthetic wellbeing score. The script uses a train/test split and a median imputation pipeline, then reports MAE, RMSE, R-squared, and fitted coefficients.

The dataset is small and synthetic. Results are for learning only; they do not establish causation or provide clinical conclusions.

Next: compare training and test performance and learn how overfitting can make a model perform poorly on unseen data.
