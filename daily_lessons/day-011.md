# Day 11 — Overfitting, Underfitting, and Model Reliability

## Learning objectives

By the end of this lesson, you should be able to:
- Explain underfitting and overfitting in plain language.
- Compare training and test performance.
- Recognize when a model memorizes the training data instead of learning patterns that generalize.
- Use a simple baseline and a regularized model comparison to assess reliability.

## 1. The core idea

A model should learn patterns that work on data it has not seen before.

- **Underfitting:** the model is too simple to capture useful patterns. It performs poorly on both training and test data.
- **Overfitting:** the model learns noise or details specific to the training set. Training performance looks strong, but test performance is noticeably worse.
- **Reasonable generalization:** training and test performance are both useful and reasonably close.

## 2. Why this matters in mental-health data

A model trained on a small synthetic wellbeing dataset may appear accurate simply because it has learned quirks in that sample. In real mental-health research, overfitting can produce misleading conclusions, especially when datasets are small, predictors are numerous, or measurements are noisy.

Always keep the test set separate from model fitting. Do not use test results to repeatedly tune a model.

## 3. Practical task

Run `python src/09_model_reliability.py`.

The script:
1. Loads the synthetic wellbeing dataset.
2. Uses sleep hours, exercise days per week, and work/study hours as predictors.
3. Splits the data into training and test sets.
4. Compares a mean-prediction baseline, linear regression, and decision trees with different maximum depths.
5. Reports training and test MAE/RMSE and the train–test RMSE gap.

## 4. How to interpret the results

- A very large training–test gap can be a warning sign of overfitting.
- Poor training and test scores can indicate underfitting.
- A smaller gap is not automatically good: both scores could be poor.
- Compare against the baseline. A complicated model is not useful if it does not improve test performance.

The dataset is small and synthetic, so results may vary with the split and should be treated as a learning demonstration, not evidence about real patients.

## Key takeaway

The goal is not to achieve the best score on training data. The goal is to build a model that performs reasonably on unseen data and whose limitations are clearly understood.
