# Day 13 — Hyperparameter Tuning with GridSearchCV

## Learning objectives

By the end of this lesson, you should be able to:
- Distinguish model parameters from hyperparameters.
- Explain how a grid search tests combinations of hyperparameter values.
- Use `GridSearchCV` with cross-validation.
- Evaluate the selected model on a separate test set without using that set for tuning.

## 1. Parameters vs. hyperparameters

A model learns **parameters** from the training data. For example, linear regression learns coefficients.

**Hyperparameters** are settings chosen before or around training. For a decision tree, examples include:
- `max_depth`: the maximum depth of the tree.
- `min_samples_leaf`: the minimum number of training observations allowed in a leaf.

A shallow tree may miss important patterns (underfitting). A very deep tree may memorize training examples (overfitting).

## 2. What GridSearchCV does

`GridSearchCV` tests the combinations you specify. For each combination, it performs cross-validation and scores the model. It then selects the combination with the best average cross-validation score.

The search only uses the training portion of the data. Keep the final test set untouched until tuning is complete.

## 3. Practical task

Run:

`python src/11_hyperparameter_tuning.py`

The script:
1. Loads the synthetic wellbeing dataset.
2. Separates a final test set.
3. Builds a preprocessing-and-decision-tree pipeline.
4. Searches several `max_depth` and `min_samples_leaf` combinations using 5-fold cross-validation.
5. Reports the best settings, cross-validation RMSE, and final test RMSE.
6. Compares the tuned tree with a simple mean-prediction baseline on the same test set.

## 4. How to interpret results

- Lower RMSE means smaller prediction errors.
- The best grid-search result is best only among the values you included in the grid.
- A tuned model is not automatically better than a simple baseline.
- A very small training dataset can make cross-validation estimates unstable.
- Do not repeatedly change the grid based on the final test score. That would make the test set part of the tuning process.

This synthetic dataset is for learning code and concepts. It is not clinical evidence or a tool for assessing individuals.

## 5. Check your understanding

1. Is `max_depth` a learned model parameter or a hyperparameter?
2. Why does GridSearchCV use cross-validation?

## Key takeaway

Hyperparameter tuning helps compare model settings systematically. Use cross-validation for selection and preserve a separate test set for the final, less biased performance check.
