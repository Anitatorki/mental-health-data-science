# Data

This folder contains datasets used for the Mental Health & Wellbeing Data Science project.

## Data safety

- Use only public, synthetic, or de-identified data.
- Do not add private patient information.
- Document the source and licensing information for external datasets.
- Keep raw data separate from processed data when possible.

## Day 2

For the first analysis exercises, we will use a small synthetic mental-health-style dataset.

The goal is to practice:

1. Loading data with Pandas
2. Inspecting columns and data types
3. Checking missing values
4. Identifying simple data-quality issues
5. Preparing data for exploratory analysis

The dataset is intentionally synthetic and does not represent real patients.
